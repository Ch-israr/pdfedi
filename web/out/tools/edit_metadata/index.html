Edit Metadata — what it does

Update your PDF's document info. Change the title, author, subject, and keywords that show up in PDF readers and search results — no desktop software needed.

How to use Edit Metadata

  1. 1Upload your PDF file (up to 50MB).
  2. 2Enter the new title, author, subject, and/or keywords.
  3. 3Click Save and download the updated PDF.

Key features

  • ✓Edit title, author, subject, keywords
  • ✓Document content untouched
  • ✓Instant download

When to use Edit Metadata

  • Set a proper title before publishing a PDF
  • Add your name as author to your documents
  • Clean up metadata inherited from a template
  • Add keywords for better document organization

Frequently asked questions

How do I change a PDF's title or author?

Upload the PDF, fill in the new title, author, subject, or keywords, and click Save. Only the metadata changes — your pages stay exactly the same.

Will editing metadata affect my document's content?

No. Metadata lives in the document info dictionary; pages, text, and images are not modified.

Why does PDF metadata matter?

PDF readers and search engines display the title and author. Correct metadata makes your documents look professional and easier to find.
