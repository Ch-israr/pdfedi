Split PDF — what it does

Divide a PDF into multiple smaller files. Extract specific page ranges (for example pages 1–3 and 5) or split every page into its own PDF. Results are delivered as a convenient ZIP download.

How to use Split PDF

  1. 1Upload your PDF file (up to 50MB).
  2. 2Choose a mode: page ranges (e.g. 1-3,5) or every page separately.
  3. 3If using ranges, enter them like 1-3,5.
  4. 4Click Split and download the ZIP containing your files.

Key features

  • ✓Split by custom page ranges (e.g. 1-3,5)
  • ✓Split every page into its own PDF
  • ✓Results delivered as a ZIP archive
  • ✓Original quality preserved

When to use Split PDF

  • Extract a chapter from an ebook
  • Separate a scanned batch into individual documents
  • Pull out specific pages to share or print
  • Break a large PDF into emailable chunks

Frequently asked questions

How do I split a PDF into separate files?

Upload your PDF, choose 'ranges' mode and enter page ranges like 1-3,5, or choose 'every' to make each page its own file. Click Split and download the ZIP.

What page range format should I use?

Use 1-based page numbers with commas and dashes, for example 1-3,5,8-10. This extracts pages 1, 2, 3, 5, 8, 9, and 10.

Can I split a PDF into individual pages?

Yes. Select the 'every' mode and each page of your PDF becomes a separate PDF file inside the ZIP download.

Is there a page limit for splitting?

There's no fixed page limit, but the 50MB upload cap applies. Very large PDFs are processed page by page to stay within server memory.
