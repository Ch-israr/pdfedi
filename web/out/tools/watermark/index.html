Add Watermark — what it does

Stamp text diagonally across every page of your PDF. Add marks like DRAFT, CONFIDENTIAL, or SAMPLE with adjustable opacity — a simple way to label document status.

How to use Add Watermark

  1. 1Upload your PDF file (up to 50MB).
  2. 2Enter your watermark text and choose an opacity level.
  3. 3Click Add Watermark and download the stamped PDF.

Key features

  • ✓Diagonal text stamp on every page
  • ✓Custom text of your choice
  • ✓Adjustable opacity

When to use Add Watermark

  • Mark drafts as DRAFT before review
  • Label sensitive files CONFIDENTIAL
  • Stamp SAMPLE on preview documents
  • Brand outgoing PDFs with your company name

Frequently asked questions

How do I add a watermark to a PDF?

Upload your PDF, type the watermark text, set the opacity, and click Add Watermark. The text is stamped diagonally on every page.

Can I control how visible the watermark is?

Yes — the opacity option lets you make the watermark subtle or bold.

Which pages get watermarked?

Every page of the PDF receives the watermark.
